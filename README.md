# Anatomie-Kartei

Karteikasten für die Klausur „Funktionelle Sportanatomie“ (EUF, HeSe 2026/27).

- `index.html` – die App (läuft komplett im Browser, Lernstand bleibt auf dem Gerät)
- `cards.json` – die Karten; wird sonntags automatisch aus neuen Vorlesungsfolien ergänzt
- Karten-IDs nie ändern oder löschen: der Lernstand hängt an ihnen.
